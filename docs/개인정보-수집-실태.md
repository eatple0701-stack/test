# 이 앱이 실제로 수집하는 개인정보 — 코드에서 확인한 목록

**작성 목적**: 개인정보 처리방침과 이용약관을 쓰실 분에게 넘기는 자료입니다.
법률 문장이 아니라 **사실 조사**입니다 — "우리가 뭘 받고, 어디에 두고, 누가
보는가". 방침 문장은 사람이 써야 하고, 이 문서는 그 앞 단계입니다.

작성 2026-08-30. 근거는 전부 저장소 안에 있고, 각 항목에 파일과 테이블을
적어 두었으니 그대로 확인하실 수 있습니다.

> ⚠️ **이 문서는 법률 자문이 아닙니다.** 수집 항목·보관 위치·전송처를
> 코드에서 확인해 정리한 것뿐입니다. 보관 기간, 법적 근거, 이용자 권리 행사
> 절차는 이 문서에 없고, 그것이 방침에서 사람이 판단해야 할 부분입니다.

## 1. 회원가입에서 직접 받는 것

`src/components/AuthSheet.jsx` · 저장 위치 `member_details` 테이블

| 항목 | 컬럼 | 필수 | 비고 |
|---|---|---|---|
| 이메일 | `email` (text) | ✅ | 로그인 식별자 겸 알림 수신처 |
| 비밀번호 | — | ✅ | **DB에 평문으로 없음.** Supabase Auth가 해시로 보관 |
| 전화번호 | `phone` (text) | ✅ | |
| 생년월일 | `birthdate` (date) | ✅ | |
| 가입 시각 | `created_at` | 자동 | |

**구글 로그인**을 쓰면 비밀번호 대신 구글이 이메일과 프로필 기본 정보를
넘겨줍니다. 이때 **전화번호와 생년월일은 구글이 주지 않아서**, 앱이 로그인
직후 따로 물어봅니다 (`docs/google-login-setup.md`에 그 흐름이 있습니다).

## 2. 프로필로 받는 것

`profiles` 테이블

| 항목 | 컬럼 | 비고 |
|---|---|---|
| 이름(표시명) | `name` | 본명일 필요 없음 |
| 국적 | `nationality` | |
| 사용 언어 | `languages` (배열) | |
| 검증된 호스트 여부 | `is_verified_host` | 팀이 설정 |

프로필 사진은 **업로드 기능이 없습니다.** 사진이 없는 사용자에게는 12종의
동물 그림 중 하나가 자동 배정됩니다(`AnimalAvatar`) — 이미지가 서버로
올라가지 않습니다.

## 3. 서비스를 쓰면서 쌓이는 것

| 테이블 | 무엇이 들어가나 |
|---|---|
| `tables` | 내가 연 밥상 — 요리, 날짜, 시간, 만나는 장소, 알아보는 방법 |
| `signups` | 내가 청한/수락된 자리, 참석 여부 기록 |
| `reviews` | 식사 후 한 줄 후기 |
| `reports` | 내가 넣은 신고 — 사유와 메모(최대 300자) |
| `blocks` | 내가 차단한 사람 (**상대에게 알려지지 않음**) |
| `notifications` | 발송된 알림 메일의 기록 |
| `pilot_team` | 팀원 계정 표시 |

## 4. 기기에만 남고 서버로 안 가는 것

브라우저 `localStorage` — 서버 전송 없음, 그 기기에서만 존재

- 언어 설정 (`bapchingu-locale`)
- 화면 테마 (밝게/어둡게)
- 저장한 장소, 방문 표시, 여권 기록
- 안내바를 닫았는지 (`sessionStorage`, 브라우저 닫으면 사라짐)

## 5. 밖으로 나가는 것 (제3자)

| 어디로 | 무엇이 | 왜 |
|---|---|---|
| **Supabase** (DB·인증) | 위 1~3 전부 | 데이터 보관처. 서버 리전 확인 필요 ← **방침에 적을 때 확인하세요** |
| **Google** | 구글 로그인 사용 시 | 로그인 인증 |
| **Gmail (팀 계정)** | 알림 메일 발송 | Edge Function이 발송 |
| **OpenStreetMap** | 지도 타일 요청 시 IP | `MapComponent.jsx:195` |
| **서울관광재단 CDN** | 등록부 사진 요청 시 | `referrerPolicy="no-referrer"`로 **어느 페이지에서 왔는지는 안 보냅니다** |
| **Vercel** | 접속 로그 (호스팅사) | |

**광고·추적 도구는 없습니다.** 코드에 분석 스크립트, 픽셀, 광고 SDK가
하나도 없는 것을 확인했습니다.

**결제 정보는 받지 않습니다.** 앱을 통해 돈이 오가지 않고, 식대는 식당에
직접 냅니다.

## 6. 누가 무엇을 보는가

- **다른 참가자**: 표시명, 국적, 사용 언어, 지금까지 연 밥상 수.
  → **이메일·전화번호·생년월일은 다른 참가자에게 보이지 않습니다.**
- **호스트**: 자기 밥상에 자리를 청한 사람의 프로필(위와 같은 범위)
- **팀**: 운영에 필요한 범위. 신고 내용은 팀에게 전달됩니다

## 7. 방침 쓰실 때 이 문서로 답 안 되는 것

코드로는 알 수 없고 **사람이 정해야 하는 것들**입니다:

1. **보관 기간** — 파일럿 종료 후 계정과 기록을 언제 지울지
2. **법적 근거** — 동의 기반인지, 각 항목의 수집 목적
3. **이용자 권리 행사 방법** — 열람·정정·삭제 요청을 어디로, 며칠 안에
4. **개인정보 보호책임자** — 이름과 연락처 (현재 앱에는
   `eatple0701@gmail.com` 하나뿐이고, 리뷰에서 "개인 지메일로 보인다"는
   지적이 있었습니다)
5. **Supabase 서버 리전** — 국외 이전 고지가 필요한지 판단하려면 확인 필요
6. **만 14세 미만** 처리 — 생년월일을 받고 있으므로 정책이 필요합니다

## 8. 지금 앱의 상태

- 푸터에 "개인정보 처리방침 · 준비 중", "이용약관 · 준비 중"이 **링크가
  아닌 회색 글자**로 있습니다 (`MainTab.jsx`)
- 가입 시트에는 **무엇을 왜 받는지 설명하는 문장이 없습니다**
- 베타 테스터 지적: *"개인정보 방침을 아직 안 썼다고 같은 화면에서 말하는
  서비스에 외국인이 개인정보를 넘기라는 요구"*

문서가 준비되면 푸터 두 자리와 가입 시트에 연결하는 작업은 몇 줄입니다.
텍스트만 주시면 바로 붙이겠습니다.
